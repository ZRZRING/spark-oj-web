# RULES.md

**如果你犯了错误被我指正，请总结并写入 `docs/RULES.md` 中。**

- 请称呼我为 zrzring，总是用中文回复我。
- 尽可能使用 element ui 的组件，以减少不必要的 css 的使用。
- 文档和代码不同时，以代码为准，并更新文档。
- 写前端代码的时候，默认后端代码是**不可修改的**，如果一定需要修改，请给出建议而并非直接修改。
- 当需要接入后端 api 的时候，可以通过 Bash(curl -s http://127.0.0.1:8000/api.json) 获取后端 api 的信息，如果不能访问，停止工作并报告给我。
- 代码、typescript 文件使用小驼峰命名法，Vue 文件使用大驼峰命名法，css 的 class 类使用中划线命名法。
- 我配置了 typescript 的下划线和小驼峰的转化，遵循规范即可。
